# Drone ESC PCB

## Overview
A custom electronic speed controller (ESC) PCB designed for brushless DC motor applications.

## Design Objectives
- Design a three-phase MOSFET power stage.
- Integrate a DRV8320 gate driver.
- Use an STM32 microcontroller for control.
- Design power distribution for a 6S LiPo battery system.

## Hardware Components
- **Microcontroller:** STM32 (exact part number to be added)
- **Gate driver:** DRV8320
- **Power MOSFETs:** TI CSD18532NQ5B
- **Design software:** KiCad
